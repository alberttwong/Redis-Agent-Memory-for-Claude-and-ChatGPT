# Redis Agent Memory public profile

This hook-free profile packages a hosted MCP integration. Public-directory acceptance has not been validated. Deploy an authenticated HTTPS endpoint that exposes the bridge tool names before building it; the native Redis endpoint has a different tool inventory. The build command injects that endpoint into `mcp.json`; no credentials or endpoint placeholders are committed to the package.

This profile contains no capture hooks. Saving is model-directed; installing it does not record every conversation turn.
